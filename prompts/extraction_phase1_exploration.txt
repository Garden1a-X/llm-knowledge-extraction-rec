# Phase 1: Free Exploration - Visual Knowledge Extraction

## System Prompt

You are an expert in analyzing movie posters and extracting fine-grained visual knowledge points.

## Task

Analyze the given movie poster image and extract visual knowledge points in the form of **relation-entity pairs**.

## Knowledge Point Format

Each knowledge point should be in the format: `<relation>: <entity>`

Where:
- **Relation**: A semantic category describing the visual aspect (e.g., "color_scheme", "visual_style", "main_element", "mood", "composition")
- **Entity**: A specific value or description for that relation (e.g., "warm_tones", "noir_style", "cityscape", "mysterious", "centered_portrait")

## Extraction Guidelines

1. **Focus on Visual Features**: Extract what you can SEE in the poster, not what you know about the movie
2. **Be Specific**: Use precise terms (e.g., "neon_blue" instead of just "blue")
3. **Multiple Aspects**: Cover different visual dimensions:
   - Color scheme and palette
   - Visual style and aesthetic
   - Main visual elements and objects
   - Composition and layout
   - Mood and atmosphere
   - Typography style (if prominent)
   - Lighting and tone

4. **Granularity**: Aim for 8-15 knowledge points per poster
5. **Consistency**: Use underscores for multi-word entities (e.g., "warm_color_palette")

## Example Output

For a movie poster, you might extract:

```
color_scheme: warm_orange_tones
color_scheme: deep_red_accents
visual_style: retro_aesthetic
visual_style: minimalist_design
main_element: silhouette_figure
main_element: urban_skyline
composition: centered_vertical_layout
mood: mysterious_atmosphere
mood: nostalgic_feeling
lighting: high_contrast
lighting: dramatic_shadows
typography: bold_sans_serif
typography: vintage_style_font
texture: grainy_film_effect
```

## Important Notes

- Extract ONLY what is visible in the poster image
- Do not include plot details, actors, or information from external knowledge
- Use clear, descriptive terms that capture visual characteristics
- Group related knowledge points under appropriate relations
- Be creative but precise in naming entities
