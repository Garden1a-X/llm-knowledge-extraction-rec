**实现难度**: ⭐⭐（需要修改代码）
**预期收益**: +1-3%

**思路**：训练初期高温（exploration），后期低温（exploitation）

```python
# src/model/losses.py - 添加方法
def get_temperature(self, epoch, max_epochs):
    """Cosine annealing temperature"""
    temp = self.temp_final + 0.5 * (self.temp_init - self.temp_final) * \
           (1 + np.cos(np.pi * epoch / max_epochs))
    return temp
```

**实现难度**: ⭐⭐（修改损失函数）

# src/model/losses.py

# 新增：item-level对比
