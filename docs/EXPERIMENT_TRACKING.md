# Baseline 实验跟踪表

*Last updated: 2026-01-17*

---

## 📊 实验配置

- **数据集**: MovieLens-1M (5-core filtered)
- **数据分割**: 70% train / 10% val / 20% test
- **排序**: Time-based ordering (TO)
- **评估模式**: **uni100** (1 positive + 99 random negatives)
- **Trials**: 5次（seeds: 42, 2023, 2024, 2025, 12345）
- **Epochs**: 300
- **评估指标**: NDCG@10 (主), Recall@10, Precision@10, Hit@10

**⚠️ 重要变更（2026-01-17）**: 所有方法已切换至uni100评估模式（从full ranking改为uni100），以支持LLM baseline方法的评估。

### **消融实验结果**（uni100评估，5 trials）

| 实验 | NDCG@10 | Recall@10 | NDCG@20 | Recall@20 | vs Ours-Full | 结论 |
|------|---------|-----------|---------|-----------|--------------|------|
| **完整模型** |
| **Ours-Full** | **0.4360 ± 0.0069** | **0.7282 ± 0.0053** | **0.4729 ± 0.0064** | **0.8818 ± 0.0038** | - | ✅ Baseline |
| **模块有效性** |
| Ours w/o Contrast | **0.4250 ± 0.0146** | **0.7188 ± 0.0168** | - | - | **-2.5%** | ✅ 证明对比学习有效 |
| Ours w/o Mask | **0.4303 ± 0.0077** | **0.7241 ± 0.0095** | - | - | **-1.3%** | ✅ 证明Mask机制有效 |
| Ours KG-only | **0.3056 ± 0.0132** | **0.5513 ± 0.0172** | - | - | **-29.9%** | ✅ 证明CF视图关键 |

**消融实验结论**：
- **对比学习**: 去除后NDCG@10下降2.5%（0.4360→0.4250），证明多视图对比学习有效
- **Mask机制**: 去除后NDCG@10下降1.3%（0.4360→0.4303），证明Mask机制对抗幻觉有效
- **CF视图**: 只用KG视图后NDCG@10骤降29.9%（0.4360→0.3056），证明CF视图是核心贡献
- **综合**: 完整模型Ours-Full在各消融版本中表现最优，验证了架构设计的有效性
