## Current Status (2024-12-26)

This is a fresh environment. The previous successful 5-epoch LightGCN test was in a different session/environment (likely with conda).

## Quick Setup (Recommended)

### Option 1: Use Conda Environment (Recommended)

If you have the conda environment from the previous session:

```bash
# Activate your conda environment
conda activate xuao_llm_kg_rec

# Verify RecBole is installed
python -c "import recbole; print(recbole.__version__)"

# Prepare data if not done
python baselines/prepare_data_for_recbole.py \
    --ml_data_dir data/ml-1m \
    --output_dir data/recbole

# Run 300-epoch training
python baselines/run_baseline.py \
    --model LightGCN \
    --dataset ml-1m \
    --data_path data/recbole \
    --device cuda \
    --epochs 300
```

### Option 2: Fresh Install (This Environment)

**WARNING**: This environment has pip cache disabled, so installations are VERY slow (10-20 minutes for PyTorch alone).

```bash
# Install dependencies (will take 20-30 minutes)
pip install torch>=2.0.0
pip install recbole==1.2.1 "numpy<2.0,>=1.24.0" "pandas<2.1.0,>=2.0.0" "scipy==1.10.1"
```

## Data Requirements

### MovieLens 1M
- Location: `data/ml-1m/`
- Files needed: movies.dat, ratings.dat, users.dat
- Posters: `data/ml-1m/posters/` (3882 images)

### RecBole Format
- Will be generated by `prepare_data_for_recbole.py`
- Output: `data/recbole/ml-1m/`
- Files: ml-1m.inter, ml-1m.item, ml-1m.user

## Troubleshooting

### "No module named 'recbole'"
- RecBole not installed in current environment
- Try Option 1 (conda) or install via pip (slow)

### "numpy.bool8 AttributeError"
- numpy 2.0 incompatibility
- Downgrade: `pip install "numpy<2.0"`

### "dok_matrix._update AttributeError"
- scipy too new
- Downgrade: `pip install scipy==1.10.1`

### Slow pip installations
- Pip cache is disabled in this environment
- Each package download is slow
- Consider using conda environment instead
